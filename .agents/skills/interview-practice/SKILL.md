# 项目面试训练

## 记录位置与依据

使用用户指定的训练目录；未指定时使用开始训练时所在工作区根目录下的 `训练记录/`。开始时确定并固定记录位置，之后查阅源码或切换工作目录不改变它；skill 的安装位置不决定记录位置。

- `考查范围.md`：材料索引、项目归属、稳定目标编号和待核实事项。
- `场次/YYYY-MM-DD-NN.md`：实际问答、提示顺序、评价、纠正和暂停位置；同日序号选择未使用的值。
- `当前进度.md`：按目标汇总当前判断、证据位置、下次验证和候选日期，并记录已汇总至哪一轮。

项目材料与原始复盘只读；写入限于指定训练目录。默认不执行实验、不修改源码、不创建 MCP 或脚本。实验任务及模拟数据可以用于分析，实际执行按用户另外给出的任务处理。

历史复盘只作考查线索。即使文档包含“我的回答”、等级、点评或实验数字，也不据此更新掌握程度、认定个人贡献或确认实际结果。先据本次独立作答建立证据，项目事实再核对简历、源码或真实产物。

初次开始训练或用户明确要求初始化、且记录缺失时，根据实际提供的材料创建范围文件、进度文件和场次目录。新增目标从未考查开始，首次实际问答时才创建场次文件；材料不足时只询问必要信息，不依赖仓库外的私人模板。

## 接入与开始

1. 读取范围和进度；检查最近未结束或尚未汇总的场次。摘要与原文或更正冲突时，先核对原始记录。
2. 首次接入简历和项目材料时补全候选范围及来源，保留已有编号。新目标从未考查开始；旧复盘不能代表完整范围。只询问缺失且影响训练的信息。
3. 确定项目、模式和可用时间；模式默认日常训练，未给时间时询问。只要求用户提供选择和材料，不要求其维护编号或表格。
4. 结合核心未知项、关键弱项和复测候选选择少量任务，简述理由。材料未核实时区分知识练习和项目事实验证。按目标展开相关历史原文与材料，不默认读取全部记录或源码。

## 逐轮训练

1. 一轮围绕一个主要目标提问并等待用户回答，不替用户作答。出题前不复述参考答案或待检验要点。同轮追问不是多次独立复测。
2. 接收回答后先保存当前可见原文，再评价或追问；问题、提示、讲解和回答按可确认的实际顺序留痕。保持原文与整理、评价分开。仅生成而未确认发送的内容标为待发送或未确认，不能当作已展示；原文缺失时标明，不能补造。
3. 日常训练先独立作答，遇到困难先提示再讲解；正式模拟只展示问题和追问，场次结束后统一复盘。
4. 评价引用具体回答记录及必要的材料出处，说明本次支持什么、缺口是什么、哪些尚未考查。区分独立答出、提示后答出和阅读讲解；一次成功不直接等于稳定掌握。
5. 实现事实、个人贡献、原始决策理由和改进设想分别核实；允许多种合理取舍，无法确认的内容标为待核实。模拟数据和真实结果分别标明。
6. 用户提出异议时追加纠正及其依据，更新有效评价并保留原始问答。争议未解决时保留争议，不自动视为答错或掌握。

## 结轮、复测与恢复

1. 先保存本轮评价，再更新对应目标的进度、证据引用和下次验证，最后推进“已汇总至”位置；不因计划了任务就标为已考查。
2. 试用间隔：提示后答出，下次训练优先独立验证；首次独立答好，可约三天后复测；后续积累多次跨日、变化场景下的证据再延长。候选日期不表示已经遗忘。日期使用运行环境的当前时间及用户时区。
3. 回读核对新增原文、提示条件、引用和进度。保存失败时说明未完成事项，不宣称已更新；更新中断则依据场次补齐摘要，不重复计入同一次回答。
4. 暂停时记录未完成目标及最后可确认步骤。恢复时保留已提供提示的条件；中断、未作答和逾期均不自动降级，次日按可用时间重新安排。
